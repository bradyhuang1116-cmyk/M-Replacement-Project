## 方案A：本地 Python 环境部署（推荐）

### 1. 安装 Miniconda

1. 下载 Miniconda：https://docs.conda.io/en/latest/miniconda.html
2. 安装时勾选 "Add to PATH"
3. 重启命令行

### 2. 获取项目代码

```bash
git clone https://github.com/bradyhuang1116-cmyk/Mitsubishi-Electric-Drawing-Replacement-Project.git
cd Mitsubishi-Electric-Drawing-Replacement-Project
```

### 3. 创建环境并安装依赖

```bash
conda create -n mitsubishi python=3.12 -y
conda activate mitsubishi
pip install -r requirements_local.txt
```

**如果安装很慢**：
```bash
pip install -r requirements_local.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4. 配置 VLM OCR 引擎

系统使用混合 OCR 模式，需要额外启动 vLLM 服务器：

1. 安装 vLLM（参考 vLLM 官方文档）
2. 下载模型 PaddleOCR-VL-1.5-0.9B
3. 启动服务器：
```bash
start_vllm_server.bat
```
4. 确认服务可用：访问 http://localhost:8080/v1/models

### 5. 启动 Web 服务

```bash
conda activate mitsubishi
python web_app.py
```

浏览器打开 http://localhost:7860

### 6. 使用流程

1. 打开 http://localhost:7860
2. 点击"加载模型"初始化 OCR 引擎
3. 上传图纸文件（TIF/PDF/JPG）
4. 选择检测首字母（默认 X、Y）
5. 点击"开始替换"
6. 等待处理完成，查看替换结果
7. 输出文件在 `output/latest/` 目录下

## 方案B：Docker 部署

> 注意：Docker 部署需要 nvidia-docker 支持 GPU 透传，配置较复杂。推荐使用方案 A。

### 1. 安装 Docker Desktop

1. 下载 Docker Desktop：https://www.docker.com/products/docker-desktop
2. 安装并重启
3. 安装 NVIDIA Container Toolkit

### 2. 启动服务

```bash
docker-compose up -d
docker-compose logs -f
```

### 3. 访问服务

- **Web界面**：http://localhost:7860

### 4. 停止服务

```bash
docker-compose down
```

## 验证部署

### 测试步骤
1. 打开浏览器访问 http://localhost:7860
2. 点击"加载模型"，确认状态显示：
   - `PaddleOCR v5 (红框定位): OK`
   - `VLM (绿/橙框+替换): OK`
3. 上传一张测试图纸
4. 点击"开始替换"
5. 确认结果 Gallery 中显示替换后的图片
6. 检查 `output/latest/ocr/` 目录下的输出文件

## 常见问题

### Q1：Python 版本不对怎么办？
**A**：必须使用 Python 3.11 或 3.12。用 conda 管理环境可以避免版本冲突。

### Q2：pip install 很慢或失败
**A**：使用国内镜像源：
```bash
pip install -r requirements_local.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q3：VLM 服务未响应
**A**：
1. 确认 vLLM 服务器已启动（`start_vllm_server.bat`）
2. 检查 http://localhost:8080/v1/models 是否正常返回
3. 确认 GPU 显存足够（至少 8GB 空闲）

### Q4：GPU 显存不足
**A**：混合模式（v5 + VLM）峰值约 12GB VRAM。如果显存不足：
- 关闭其他占用 GPU 的程序
- 或使用更大显存的 GPU

### Q5：替换后字体不对
**A**：确认 `fonts/DingLieSongKeTi/dingliesongtypeface20241217-2.ttf` 文件存在。
