# 区域检测详解

> `modules/region_detector.py` 的 `detect_all_regions(image)` —— 图纸编号区域的检测与裁切全流程。
> 含整体裁切、四个搜索框的识别/裁切逻辑、底层函数细节。

## 总流程

```
原图
 ├─ 0. 纵向自动旋转(高>宽则转横)
 ├─ Phase A: 检测图纸边框 + 算出 3 个搜索区坐标
 ├─ Phase B: 裁切 3 个子图 → 并行 OCR → 红/绿框检测；橙框依赖红框
 └─ Phase C: 工厂注意区检测(V6 像素法)
```

四个目标框：

| 框 | 找什么 | 方法 | 引擎 | 依赖 |
|---|---|---|---|---|
| 🔴 红框 | MATERIAL CODE **列** | 关键词锚定 + 网格线追踪 | v5(中英) | 图纸边框 |
| 🟢 绿框 | 右下**编号** | 4 层降级 OCR | v5 | 无(与红框并行) |
| 🟠 橙框 | 左上**编号** | 3 策略 + 合体拆分 | VLM | **红框** |
| 🟡 工厂注意 | 区内多个**编号** | V5 粗扫 → VLM 精定位 | v5+VLM | 排除前三框 |

---

## 0. 预处理：纵向旋转
图纸约定"宽 > 高"。若 `img_h > img_w`，`_auto_rotate_portrait` 转正并记 `metadata["rotation"]`。

## Phase A：边框检测 + 搜索区坐标

### 图纸边框 `_detect_drawing_frame`
- 形态学检测**跨越大部分宽/高的长线条**(画框线)，取最外侧水平+垂直线组边框
- 超大图(长边 > 2100)先降采样检测，坐标映射回原图
- 多阈值尝试 `[150,130,100]`，水平核长 = `宽×0.5`
- 失败 → 回退图片边界(2% 内缩)

### 三个搜索区坐标
| 框 | X 起 | 宽 | Y 起 | 高 |
|---|---|---|---|---|
| 红框 | `img_w×8%` | 到 `frame.x + frame.w×2.8/8` | 0 | `img_h×95%` |
| 绿框 | `img_w×5/8` | 到右边界 | `img_h×5/6` | 到下边界 |
| 橙框 | — | Phase B 后依赖红框动态算 | — | — |

### 统一裁切缩放 `_crop_and_scale`
- 按搜索区裁子图；**最长边 > 2100px → 等比缩放到 2100**(`MAX_SEARCH_EDGE`，INTER_AREA)，返回 scale
- 检测在子图坐标做，`_map_bbox_back` 用 scale + 搜索区偏移映射回原图(坐标三段映射)

## Phase B：四框识别逻辑

### 🔴 红框 `_locate_material_code_column`
要找"MATERIAL CODE 这一列"，先找表头关键词，再用表格线圈整列。

1. **关键词检测**(子图顶部 20%/100px 局部 OCR)
   - 英文 OCR 模糊匹配 `MATERIAL CODE`(difflib，阈值 0.7)
   - 没中 → 中文 OCR 再试("零部件图号"等)
   - 都没中 → 返回 None(红框失败)
2. **相邻列锚点**
   - DEF 列(左邻)：`cx < 关键词cx` 且最靠右的(最近)
   - 品/群 列(右邻)：`cx > 关键词cx` 且最靠左的
3. **网格线追踪列边界** `_trace_vertical_table`
   - ① 关键词附近窄带(高±5%/100px，左右±400px)检测强竖线
   - ② 窄带竖线 <2 条 → 向下扩展(关键词下方 30% 高，降阈值)——表格体在关键词下方
   - ③ DEF/品群锚点 + 竖线确定列宽
   - ④ 列边界竖线的 y 范围 = 表格高度(竖线只在表格内存在)
   - ⑤ 列内检测水平线确定数据行边界
4. **验证 + 修正**
   - `_validate_material_code_column`：回 OCR 确认列内确有 MATERIAL CODE(精确命中则旁路)
   - `_fix_dwg_left_boundary`：修正列左边界

### 🟢 绿框 `_locate_bottom_right_number`(4 层降级)
找 `Y/X/B/H` 开头编号，逐层加力：

| 层 | 做什么 | 解决 |
|---|---|---|
| L1 全区域 OCR | 直接 OCR 整子图找编号 | 正常 |
| L1a 右竖线裁剪 | 找右竖线裁掉跨单元格内容 | 去页码(`A216H`、`C928+2/2`) |
| L1b 直接验证 | 编号合法直接返回 | — |
| L1c 截断修复 | ≥7 字符疑似截断 → 向右扩 2.5 字符宽、上下扩 50% 重 OCR | 修 `A360` 类截断 |
| L2/L3 按长线裁切 | 沿表格线裁切再 OCR | L1 大区域失败 |
| L4 预处理增强 | 二值化/增强后重 OCR | 大字号/低对比度 |

失败 → `_fallback_detect_bottom_right_number` 兜底。

### 🟠 橙框 `_locate_top_left_number`(依赖红框)
- 搜索区：红框成功 → `(0,0, 红框左边界, 红框上边界)`；红框失败 → 固定左上角 `(0,0, w×2/8, h×2/12)`
- 用 **VLM** 引擎，3 策略：
  1. 找独立 Y 编号(原始 + 去空格 + 模糊回填三种匹配)
  2. 编号与 `DWG NO`/图号**合体识别** → 沿竖线从左逐步裁切重 OCR，切出编号
  3. 兜底搜所有 OCR 文本

### 🟡 工厂注意区 `factory_note_pixel.detect_factory_note_codes_v6`
V5 粗扫 → VLM 精定位(VLM 慢，先粗筛)：
```
1. erase_drawing_border  擦图纸外框线
2. find_bottom_span_y    性能裁切(只看有内容的下半部)
3. 切成多个 crop
4. V5 粗扫每 crop        _v5_run + _v5_filter_y(快，筛是否含 Y 编号)
5. 命中的 crop 才进 VLM   _vlm_annotate_single(精，精确定位)
6. VLM polygon 换算回原图坐标 → [{code, bbox, confidence}]
```
失败回退：`PP-DocLayoutV3` 版面检测(排除已检出的红/绿/橙区)。

## 底层函数细节

### `make_pattern` — 编号正则
```python
单字母: rf"{C}(?=[A-Z0-9]*\d)[A-Z0-9]{{6,}}"
多字母: rf"[{chars}](?=[A-Z0-9]*\d)[A-Z0-9]{{6,}}"
```
编号定义 3 条：
1. 首字母 ∈ `Y/X/B/H`(`DEFAULT_PREFIXES`，可传 prefixes 覆盖)
2. 首字母后 ≥6 位字母数字 `[A-Z0-9]{6,}`
3. 前瞻 `(?=[A-Z0-9]*\d)`：这 ≥6 位里至少含 1 个数字 → 排除纯字母词(`YARIABLE` 不是编号)

设计要点：
- **不用 `\b` 词边界**：编号前后粘任何字符都要识别(`01.021YA057C800-01` 能抠出编号)
- `H` 在前缀里 → 替换后的 `HYA...` 也能识别(用于回检验证)

### `FUZZY_DIGIT_MAP` — OCR 纠错
OCR 把数字误认成符号，匹配前先纠正：
```
'/' '!' '|' '\\' → '1'        '(' ')' → '0'
```
另有归一化表(VLM 比对用，非替换)：`O→0 I→1 S→5 Z→2 B→8`，判断 VLM 返回 token 是否等于目标(容忍形近字)。

### `_detect_vertical_lines` — 竖线检测（红框列追踪基础）
```
高斯模糊去噪
 → OTSU 二值(反相，线变白)
 → 形态学开运算，竖核 (1 × min_line_height)，iterations=2  ← 只留够高竖线
 → 找轮廓，每条取 (中心x, y起, y止, 高)
 → 按 x 排序; 相邻 x 差 ≤8px 合并(同线断点)
 → 返回 x列表 + y范围(只统计高度 > 最高线50% 的长线)
```
要点：
- `min_line_height` 滤掉文字笔画短竖；红框窄带用 `band_h×0.3`，扩展搜索降到 `×0.1`
- 竖线只在表格内存在 → 竖线 y 范围 = 表格高度
- 水平线同理 `_detect_horizontal_lines`(横核)，定数据行边界

### `_localize_y_box` — VLM 精定位收紧框（工厂注意区）
VLM 给的 polygon 较粗(可能含整行)，收紧到只覆盖该 Y token：
```
1. polygon → 包围盒，按字高 pad 外扩(字高×0.6，≥12px)裁子图
2. 灰度 → OTSU 二值 → _column_runs 算列方向笔画连续段(runs)
3. token 候选: 原token + 去尾字符的短token(若也合法)
4. 列方向网格扫描候选 [左,右] 边界:
   - _snap_to_runs: 边界吸附到实际笔画段(不切在字中间)
   - 窗口内重 OCR，归一化比对是否等于目标
5. 命中 → 原图坐标 polygon; 不中 → _fallback_box 用笔画段兜底
```
核心：VLM 定位"哪行有编号"(粗) → 像素级笔画分析收紧到"恰好框住编号几个字"(精)，替换时不涂到旁边字。

## 关键阈值汇总

| 常量 | 值 | 用途 |
|---|---|---|
| `MAX_SEARCH_EDGE` / `MAX_EDGE` | 2100 | 子图最长边缩放上限 |
| 编号最小长度 | 6 位 | `[A-Z0-9]{6,}` |
| 模糊匹配阈值 | 0.7 | MATERIAL CODE difflib |
| 竖线合并间距 | 8px | 同线断点合并 |
| 长线判定 | 最高线 ×0.5 | 算表格 y 范围 |
| VLM 框 pad | 字高×0.6(≥12) | 收紧前外扩 |
| DEFAULT_PREFIXES | Y/X/B/H | 编号首字母 |

## 一句话区分四框
- 🔴 红框：找 **列**（关键词 MATERIAL CODE + 网格线），v5
- 🟢 绿框：找右下**编号**（4 层降级 OCR），v5，与红框并行
- 🟠 橙框：找左上**编号**（3 策略 + 合体拆分），VLM，依赖红框
- 🟡 工厂注意：找区内多**编号**（V5 粗扫 → VLM 精定位），排除前三框
