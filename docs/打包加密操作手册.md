## 步骤 3：加密（Nuitka 编译 .pyd）

### 3.1 创建输出目录

```powershell
Set-Location D:\day\2026\202606\20260611\M-Replacement-Project
New-Item -ItemType Directory -Force -Path build\nuitka | Out-Null
```

### 3.2 编译 config.py

```powershell
python -m nuitka --module config.py --output-dir=build\nuitka --assume-yes-for-downloads
```

### 3.3 编译 modules 下全部模块（除 __init__.py）

```powershell
Get-ChildItem modules\*.py |
  Where-Object { $_.BaseName -ne '__init__' } |
  ForEach-Object {
    Write-Host "编译 $($_.Name) ..."
    python -m nuitka --module $_.FullName --output-dir=build\nuitka --assume-yes-for-downloads
  }
```

| 项目 | 说明 |
|------|------|
| 数量 | `config.py` + `modules\` 下除 `__init__.py` 外每个 `.py` |
| 首次耗时 | 约 30～60 分钟（下载 MinGW） |
| 不编译 | `api/`、`start_v2.py`、`modules/__init__.py`、`manual_editor/` |

### 3.4 验证

```powershell
(Get-ChildItem build\nuitka\*.pyd).Count
Get-ChildItem build\nuitka\*.pyd | Select-Object Name
```

应看到多个 `*.cp310-win_amd64.pyd`，且包含 `config.cp310-win_amd64.pyd`。

### 3.5 单文件重编（某模块失败时）

```powershell
python -m nuitka --module modules\batch_processor.py --output-dir=build\nuitka --assume-yes-for-downloads
```

将 `batch_processor.py` 换成对应文件名即可。

## 步骤 6：下载离线 Python 依赖

`paddlepaddle-gpu==3.3.0` **不在 PyPI 官方源**，必须从 Paddle **cu129（CUDA 12.9）** 源下载。  
直接 `pip download -r requirements_local.txt` 会报 `No matching distribution found`。

```powershell
Set-Location D:\day\2026\202606\20260611\M-Replacement-Project
New-Item -ItemType Directory -Force -Path NodexelOCR_Delivery\offline\offline_wheels | Out-Null

pip download -r requirements_local.txt `
  -d NodexelOCR_Delivery\offline\offline_wheels `
  --extra-index-url https://www.paddlepaddle.org.cn/packages/stable/cu129/

Copy-Item requirements_local.txt NodexelOCR_Delivery\offline\
```

> `oracledb` 已含在 `requirements_local.txt` 中，无需单独 download。  
> 需能上网；**不需要显卡**（只下载 wheel，不运行）。  
> 若仅 `paddlepaddle-gpu` 失败，可单独执行：
>
> ```powershell
> pip download paddlepaddle-gpu==3.3.0 `
>   -d NodexelOCR_Delivery\offline\offline_wheels `
>   -i https://www.paddlepaddle.org.cn/packages/stable/cu129/
> ```

## 步骤 7：组装 NodexelOCR_Delivery

可运行 `scripts\assemble_delivery.bat`，或手动执行下列命令。

### 7.1 创建目录

```powershell
Set-Location D:\day\2026\202606\20260611\M-Replacement-Project

New-Item -ItemType Directory -Force -Path NodexelOCR_Delivery\app\modules | Out-Null
New-Item -ItemType Directory -Force -Path NodexelOCR_Delivery\ManualEditor | Out-Null
New-Item -ItemType Directory -Force -Path NodexelOCR_Delivery\config | Out-Null
New-Item -ItemType Directory -Force -Path NodexelOCR_Delivery\docs | Out-Null
New-Item -ItemType Directory -Force -Path NodexelOCR_Delivery\offline | Out-Null
```

### 7.2 复制加密后的 .pyd

```powershell
Copy-Item build\nuitka\config.cp310-win_amd64.pyd NodexelOCR_Delivery\app\config.pyd

Get-ChildItem modules\*.py |
  Where-Object { $_.BaseName -ne '__init__' } |
  ForEach-Object {
    $pyd = "build\nuitka\$($_.BaseName).cp310-win_amd64.pyd"
    Copy-Item $pyd "NodexelOCR_Delivery\app\modules\$($_.BaseName).pyd"
  }

Copy-Item modules\__init__.py NodexelOCR_Delivery\app\modules\
```

### 7.3 复制应用代码

```powershell
Copy-Item api NodexelOCR_Delivery\app\api -Recurse -Force
Copy-Item fonts NodexelOCR_Delivery\app\fonts -Recurse -Force
if (Test-Path app_config) { Copy-Item app_config NodexelOCR_Delivery\app\app_config -Recurse -Force }
Copy-Item start_v2.py NodexelOCR_Delivery\app\
Copy-Item dist\ManualEditor.exe NodexelOCR_Delivery\ManualEditor\
```

### 7.4 复制前端、配置、部署脚本、文档

```powershell
# 前端（步骤 5 已构建则已存在；否则再运行 build_dashboard.bat）
# 部署脚本（客户机傻瓜式安装）
Copy-Item scripts\deploy\*.bat NodexelOCR_Delivery\
Copy-Item scripts\install_service.bat NodexelOCR_Delivery\ -ErrorAction SilentlyContinue
Copy-Item scripts\install_service_云端API.bat NodexelOCR_Delivery\ -ErrorAction SilentlyContinue
Copy-Item scripts\install_service_本地GPU.bat NodexelOCR_Delivery\ -ErrorAction SilentlyContinue
Copy-Item scripts\离线安装.bat NodexelOCR_Delivery\ -ErrorAction SilentlyContinue

Copy-Item .env.example NodexelOCR_Delivery\config\.env.example -ErrorAction SilentlyContinue
Set-Content -Path NodexelOCR_Delivery\config\server.properties.example -Value @"
# 本机 IP（举例）
server.ip=192.168.10.101
"@ -Encoding UTF8

Copy-Item docs\部署手册.md NodexelOCR_Delivery\docs\
Copy-Item docs\部署手册_本地GPU模式.md NodexelOCR_Delivery\docs\
Copy-Item docs\部署手册_云端API模式.md NodexelOCR_Delivery\docs\
```

## 附录 A：使用 cmd 时的等价写法

PyCharm 终端可先输入 `cmd` 进入 cmd，再执行：

**编译（cmd）：**

```bat
cd /d D:\day\2026\202606\20260611\M-Replacement-Project
mkdir build\nuitka 2>nul

python -m nuitka --module config.py --output-dir=build\nuitka --assume-yes-for-downloads

for %f in (modules\*.py) do @if /I not "%~nf"=="__init__" python -m nuitka --module "modules\%~nf.py" --output-dir=build\nuitka --assume-yes-for-downloads
```

> 注意：`for %f` 只能在 **cmd 窗口直接输入**；写在 `.bat` 文件里要用 `%%f`。

**组装 .pyd（cmd）：**

```bat
copy build\nuitka\config.cp310-win_amd64.pyd NodexelOCR_Delivery\app\config.pyd
for %f in (modules\*.py) do @if /I not "%~nf"=="__init__" copy build\nuitka\%~nf.cp310-win_amd64.pyd NodexelOCR_Delivery\app\modules\%~nf.pyd
```
