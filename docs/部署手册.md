# NodexelOCR 部署手册（总览）

> 客户现场 / 联调机部署入口

---

## 模式对比

| | [云端 API 模式](部署手册_云端API模式.md) | [本地 GPU 模式](部署手册_本地GPU模式.md) |
|---|---|---|
| GPU | 不需要 | 必须 ≥12GB |
| Docker / tar.gz | 不需要 | 需要 |
| 公网 | 需要 | 可不依赖 |
| 生产 | 仅联调 | **推荐** |

---

## 交付包内容（前后端一体）

| 目录/文件 | 说明 |
|-----------|------|
| `app\` | 后端 API（:8000） |
| `frontend\` | Dashboard 网页（:3000） |
| `*.bat` 部署脚本 | 根目录，按模式选云端/本地脚本 |
| `offline\` | Miniconda、wheel、WinSCP 等 |
| `docs\` | 本套部署文档 |
